# FemCurrent — Les voix et les actions des femmes

Plateforme officielle de connaissances, de médias et d'innovation sociale qui valorise le leadership des femmes en République Démocratique du Congo.

## Architecture
- **Site Officiel Adopté** : `index.html` (Application complète avec routage client, 24 rubriques, Live Search, Formulaire interactif, Thème sombre Observatoire)
- **Logos officiels** : `logo/`
- **Photoreportages & Assets** : `public/`
- **Serveur de production** : `server.js` (Node.js natif, 0 dépendance lourde, démarrage instantané)
